# lab-assist-ai
**LabAssistAI** é um assistente inteligente para laboratórios de pesquisa baseado em Retrieval-Augmented Generation (RAG). A plataforma permite consultar procedimentos operacionais, normas de biossegurança, documentação científica, manuais de equipamentos e processos administrativos por meio de uma interface conversacional, centralizando o conhecimento institucional e facilitando o acesso à informação confiável.
